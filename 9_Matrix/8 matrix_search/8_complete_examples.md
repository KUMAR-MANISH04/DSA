# 8. COMPLETE EXAMPLES

Example 1: 3×3 Matrix
```
int[][] matrix = {
    {1, 4, 7},
    {2, 5, 8},
    {3, 6, 9}
};
searchEfficient(matrix, 5);  // Found at (1, 1)
```

Example 2: 2×4 Matrix
```
int[][] matrix = {
    {1, 3, 5, 7},
    {2, 4, 6, 8}
};
searchEfficient(matrix, 4);  // Found at (1, 1)
```

Example 3: Single Row
```
int[][] matrix = {{1, 2, 3, 4, 5}};
searchEfficient(matrix, 3);  // Found at (0, 2)
```
