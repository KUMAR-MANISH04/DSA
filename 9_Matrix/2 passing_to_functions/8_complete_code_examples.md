# 8. COMPLETE CODE EXAMPLES

This folder contains practical C++ examples demonstrating the methods described in previous sections.

Examples included (source files in `examples/`):
- `example6_double_pointer.cpp` — Double pointer generic matrix
- `example7_array_of_pointers.cpp` — Array of pointers and jagged array example
- `example8_vector_of_vectors.cpp` — Vector of vectors implementation
- `example9_array_of_vectors.cpp` — Array of vectors with dynamic columns

Each example is small, prints output to stdout, and includes cleanup where needed.
