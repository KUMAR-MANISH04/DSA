# 1. BASICS OF 2D ARRAYS

## Declaration & Initialization
- 2D Array Structure: 3 rows × 2 columns
- Format: `datatype array_name[rows][columns];`

Example:
```
int arr[3][2] = {
    {10, 20},
    {30, 40},
    {50, 60}
};
```

Visual Output:
Row 0: [10] [20]
Row 1: [30] [40]
Row 2: [50] [60]

## 3D Arrays (brief)
- Three levels of nesting with curly brackets
- Format: `datatype arr[d1][d2][d3];`

Example:
```
int arr[2][2][2] = {
    {{1, 2}, {3, 4}},
    {{5, 6}, {7, 8}}
};
```
