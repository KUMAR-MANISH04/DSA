# 8. COMPLETE CODE EXAMPLES

This file contains references to the C++ example files in `examples/` and short descriptions.

- `examples/example1_static.cpp` — Static 2D array traversal
- `examples/example2_double_pointer.cpp` — Double pointer dynamic 2D array
- `examples/example3_vector_of_vectors.cpp` — Vector of vectors
- `examples/example4_variable_sized.cpp` — Variable-sized array example (compiler dependent)
- `examples/example5_jagged_double_pointer.cpp` — Jagged array using double pointers

Each example prints the array contents to stdout. See `README.md` in this folder for compile/run instructions.
